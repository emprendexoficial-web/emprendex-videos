# emprendex-videos

Videos y portadas públicos de la página «Empieza con EmprendeX».
Se sirven con jsDelivr para que carguen en cualquier navegador, también dentro de TikTok e Instagram:

`https://cdn.jsdelivr.net/gh/emprendexoficial-web/emprendex-videos@v1/v1/<archivo>`

Cada versión nueva va en su propia carpeta y etiqueta (v1, v2…), para que el caché nunca sirva un archivo viejo.
